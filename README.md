# Event Prime Close - Image downloading website

Welcome to our Event Selling Platform, a robust web application designed to facilitate the sale of event tickets by companies and provide a seamless purchasing experience for users. This platform leverages modern technologies and integrates secure payment processing via Stripe.



## Features

Ticket Listings: Companies can list events and corresponding ticket options with details such as price, quantity available, and event date.

User Registration and Authentication: Secure user accounts allow individuals to browse, purchase tickets, and manage their orders.

Shopping Cart: Users can add tickets to their cart, review selections, and proceed to checkout for payment.

Payment Integration: Integration with Stripe ensures secure and reliable payment processing for ticket purchases.

Order Management: Users can view past orders, check ticket details, and receive confirmation emails upon successful purchase.

Responsive Design: Optimized for desktop and mobile devices, offering a consistent and user-friendly experience across platforms.


## Technologies Used

- React: A popular JavaScript library for building user interfaces.
- context-hooks: A predictable state container for managing application state.
- Tailwind-CSS: A modern CSS library for Building UI faster.

- React Router: A routing library for handling navigation in React applications.
- NodeJs
- ExpressJs
- MongoDb
- Stripe
